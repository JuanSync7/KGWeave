# KGWeave AST Demo

A static, dependency-free web app that visualises the pyslang
SystemVerilog AST + semantic knowledge graph extracted from
`research/ast_experiment/corpus/`. Click any node in the graph to jump
to its source span; run canned queries to animate multi-hop traversals;
walk the guided tour to see how 89 S-rules light up across 10 example
files.

## Live demo

After enabling GitHub Pages (Settings -> Pages -> Source: `gh-pages`
branch), the site is served at:

```
https://<your-github-username>.github.io/KGWeave/
```

The `gh-pages` branch is published automatically by
`.github/workflows/demo-deploy.yml` on every push to `main`.

## Run locally

```
# 1. Rebuild graph.json (one-time per corpus change)
uv run python research/ast_experiment/scripts/export_demo_graph.py

# 2. Serve the static demo
cd research/ast_experiment/demo
python3 -m http.server 8765

# 3. Open http://127.0.0.1:8765/web/ in a browser
```

## Run the E2E tests

```
cd research/ast_experiment/demo/e2e
npm install
npx playwright install chromium
npx playwright test
```

See `e2e/README.md` for the full spec list.

## What's in the box

- `web/` — single-page app (index.html + app.js + query.js + tour.js +
  gallery.js + style.css). Ships no bundled JS; ESM imports come from
  `esm.sh` CDN.
- `data/graph.json` — precomputed graph (4 MB raw, ~280 KB gzipped).
  7222 nodes / 7721 edges over the 11-file corpus.
- `data/queries.json` — 12 canned queries that drive the dropdown.
- `data/tour.json` — 14-step guided tour, family-by-family.
- `data/gallery.json` — 10 use-case cards with 23 example queries.
- `e2e/` — Playwright spec suite (6 specs, ~12 tests).
- `SPEC.md` — locked acceptance spec (read this first to extend).
- `DEMO_LESSONS.md` — append-only sequential lessons from SA1..SA6.

## Architecture

Static-only by design: pyslang runs at build time inside
`scripts/export_demo_graph.py`, emits `data/graph.json`, and never
ships to the browser. Cytoscape.js renders the graph; CodeMirror 6
renders source; a hand-rolled JS BFS engine in `query.js` powers the
query bar. There is no backend.
