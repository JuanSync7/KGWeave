# v1.8 charter — Python semantic polish (alias + scope resolution + class protocol)

**Status:** proposed. Not started.
**Branch (when started):** `kgweave/kuzu-port` (continues).
**PR target:** continues #1.

## Why v1.8 exists

v1.7 shipped 9 walker kinds with scope-aware parenting and a per-decorator
semantic connector. Four follow-ups were explicitly queued:

1. Lambda/comprehension captures are currently raw Name strings — they don't
   resolve against actual lexical scopes (so `nonlocal` / `global` / walrus
   are invisible to connectors).
2. Decorator promotion is exact-name match — `from dataclasses import dataclass as _dc` doesn't promote.
3. Metaclass + descriptor protocol are unannotated.
4. Conditional imports beyond `TYPE_CHECKING` (`if sys.version_info >= ...`,
   `try/except ImportError`) all get `runtime=True` today.

Plus one infra item carried since v1.5: **CI disk-budget guard**. Still
blocked on the first green full-suite run, so it remains a stretch item.

**Out of scope for v1.8:** Builder #4 in a new language. Now unblocked by
v1.7-#1, but deserves its own slate (size L, separate charter, separate PR
discussion).

## Scope

### #1 — Alias-aware decorator promotion
**Size:** S. **Risk:** low (connector-only).
- Today `PyDecoratorSemanticsConnector` matches decorator strings exactly
  against `{property, dataclass, dataclasses.dataclass, pytest.fixture}`.
- Per-file import-rename map: walk `PyImport` rows in the same file as the
  `PyClass`/`PyFunction`, build `local_name → canonical_name`, normalise
  decorator strings through that map BEFORE the closed-table lookup.
- Handles: `from dataclasses import dataclass as _dc; @_dc class Foo`,
  `import pytest as pt; @pt.fixture def f`, `from functools import cached_property as cp; @cp def m`.
- Out of scope this item: dynamic decorators (`@some_function_returning_decorator()`).

### #2 — Conditional imports beyond `TYPE_CHECKING`
**Size:** S. **Risk:** low.
- Today `if TYPE_CHECKING: import x` sets `runtime=False`. Other conditional
  imports (`try/except ImportError`, `if sys.version_info >= (3, 11):`) all
  silently get `runtime=True`.
- Walker addition: detect three additional shapes and set `runtime=False`
  or add a new `import_guard` payload field:
  - `try: import X / except ImportError: ...` → `import_guard="try-import"`
  - `if sys.version_info ...:` block → `import_guard="version-guard"`
  - `if <name not TYPE_CHECKING>:` block → `import_guard="conditional"`
- Closed payload set; document it. Existing TYPE_CHECKING tests still pass.

### #3 — Capture resolution against lexical scopes
**Size:** M. **Risk:** medium (new connector + scope index).
- Today `PyLambda.captures` and (implicitly via PARENT_OF) `PyComprehension`
  capture-equivalent are raw Name strings. Connectors can't tell whether
  `captures=["y"]` resolves to an outer local, a module-level binding, a
  builtin, or undefined.
- New connector `py_scope_resolution.py`:
  - Per-file static scope index: walk PyModule + every nested
    PyFunction / PyClass / PyComprehension / PyLambda, collect parameters,
    assignments, `nonlocal` decls, `global` decls, walrus targets, comp
    iter-targets.
  - For each PyLambda/PyComprehension, classify every capture as
    `"local-in-enclosing"` / `"module-level"` / `"builtin"` / `"unresolved"`.
  - Walker stays pure; connector runs after walker and writes back to the
    payload JSON.
- Cross-file resolution is out of scope (queue for v1.9).

### #4 — Metaclass + descriptor protocol annotations
**Size:** M. **Risk:** medium (walker + connector).
- Walker: emit `metaclass: str | None` on `PyClass` payload when a class
  declares `metaclass=...` keyword in its bases.
- Connector: detect classes that implement the descriptor protocol
  (`__get__` + optionally `__set__` / `__delete__`) and tag
  `PyClass.semantic_role = "descriptor"`. Reuse the
  PyDecoratorSemanticsConnector field convention.
- Out of scope: `__set_name__`, runtime type creation via `type(name, bases, dict)`.

## Validation gates

1. Every sub-item has its own TDD-loop test commit BEFORE the impl commit.
2. Each commit: targeted dir green at 0 failures.
3. No `--ignore` or `--deselect` of any pre-existing test.
4. v1.4 meta tests still green.
5. v1.5/v1.6/v1.7 perf floors hold:
   - quickstart wall ≤ 10 s
   - SV writer N=1000 ≤ 3 s
   - Py writer N=1000 ≤ 6 s
6. JOURNAL retro at end with **What we did / Lessons learnt / Next moves**.

## Order of operations

1. **#1 alias-aware decorator** (S, connector-only, cheap win).
2. **#2 conditional imports** (S, walker payload addition).
3. **#3 capture resolution** (M, new connector consuming v1.7-#5 output).
4. **#4 metaclass + descriptor** (M, walker + connector, last because it
   touches the same connector field convention as #1).

Steps 1+2 are S-size and ship in an hour each. Steps 3+4 are the M items
that produce the slate's headline semantics. #3 lands before #4 so #4 can
reuse the per-file scope-index helper if convenient.
