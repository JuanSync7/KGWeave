# Code ↔ elab ↔ graph mapping (per construct in fifo.sv)

One row per source-level construct present in `fifo.sv`. Each row gives the
exact snippet, the pyslang class that hosts it, the graph fragment the lift
produces, and the rule the reverse engine uses to recover the SV text.

| Snippet from fifo.sv                              | pyslang class(es)                                                       | Graph fragment                                                                                                                  | Reverse rule                                                                 |
|---------------------------------------------------|-------------------------------------------------------------------------|----------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------|
| `module fifo #(...) (...); ... endmodule`         | ModuleDeclarationSyntax + ModuleHeaderSyntax + Token(`endmodule`)       | one `ModuleDeclarationSyntax` node, ordered children: SyntaxList(attrs), ModuleHeader, SyntaxList(members), Token(EndModule)     | depth-first child emit; tokens emit trivia+rawText                            |
| `#( parameter int DEPTH = 8, parameter int WIDTH = 32 )` | ParameterPortListSyntax → ParameterDeclarationSyntax → IntegerTypeSyntax + DeclaratorSyntax + EqualsValueClauseSyntax | nested child edges as above; literal `8` lives on Token rawText payload | structural emit; integer literal token preserves text                         |
| `input logic clk,`                                | AnsiPortListSyntax → ImplicitAnsiPortSyntax → VariablePortHeaderSyntax + DeclaratorSyntax | port list of children with `direction`, `varType`, `name` tokens                                                                | structural emit                                                              |
| `logic [WIDTH-1:0] mem [DEPTH];`                  | DataDeclarationSyntax + IntegerTypeSyntax(with packed dim) + DeclaratorSyntax + VariableDimensionSyntax + RangeDimensionSpecifierSyntax | nested dimension nodes; expressions inside RangeSelect carry BinaryExpressionSyntax(WIDTH-1) etc.                                | structural emit                                                              |
| `assign full = (count == DEPTH);`                 | ContinuousAssignSyntax + ExpressionStatementSyntax (lhs/rhs are expressions) + BinaryExpressionSyntax + ParenthesizedExpressionSyntax + IdentifierNameSyntax | binary `==` token's rawText preserved on the operator Token leaf                                                                | structural emit                                                              |
| `always_ff @(posedge clk or negedge rst_n) begin ... end` | ProceduralBlockSyntax + TimingControlStatementSyntax + EventControlWithExpressionSyntax + BinaryEventExpressionSyntax + SignalEventExpressionSyntax + BlockStatementSyntax | TimingControl wraps event expression tree; Block wraps inner statements                                                          | structural emit                                                              |
| `if (!rst_n) begin ... end else begin ... end`    | ConditionalStatementSyntax + ConditionalPredicateSyntax + ConditionalPatternSyntax + ElseClauseSyntax + PrefixUnaryExpressionSyntax | predicate/pattern wrappers preserved; `!` operator on Token leaf                                                                  | structural emit                                                              |
| `case ({...}) 2'b10: ...; default: ...; endcase`  | CaseStatementSyntax + ConcatenationExpressionSyntax + StandardCaseItemSyntax + DefaultCaseItemSyntax + IntegerVectorExpressionSyntax | each case item is its own child; `2'b10` is an IntegerVectorExpressionSyntax with Token leaves carrying text                      | structural emit                                                              |
| `wr_ptr <= '0;` / `mem[wr_ptr[$clog2(DEPTH)-1:0]] <= din;` | BinaryExpressionSyntax(`<=`) + LiteralExpressionSyntax (`'0`) + IdentifierSelectNameSyntax + ElementSelectSyntax + BitSelectSyntax + RangeSelectSyntax | nested select chain modeled as nested children                                                                                  | structural emit                                                              |
| `wr_ptr + 1'b1`                                   | BinaryExpressionSyntax + IntegerVectorExpressionSyntax                  | binary op with sized vector literal on Token leaf                                                                                | structural emit                                                              |
| `$clog2(DEPTH)`                                   | InvocationExpressionSyntax + SystemNameSyntax + ArgumentListSyntax + OrderedArgumentSyntax + IdentifierNameSyntax | system-name Token leaf carries `$clog2` text; argument list mapped 1:1                                                            | structural emit                                                              |
| comments / whitespace                              | trivia on adjacent Tokens                                              | `node.payload.trivia` ordered list of `{kind, text}`                                                                              | emitted before each Token's rawText                                          |
